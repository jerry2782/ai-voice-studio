# AI Voice Studio V0.4.0 — ArboTTS

Mobile-first PWA shell for the official ArboTTS browser studio.

- TTS engine: ArboTTS official client-side WebAssembly demo.
- Languages and speaker personas: those currently exposed by the official demo.
- No Render backend, API key, or credit card required by this static app.
- First use requires internet to load the official studio and model/runtime assets.
- The official demo currently exposes WAV export; MP3 export is not claimed in this version.

Official studio: https://arbo-team.github.io/arbotts-demo/

Hosted app: https://jerry2782.github.io/ai-voice-studio/

This version embeds the official studio when allowed by the provider. If embedding is blocked by browser/security policy, use the "Buka Studio ArboTTS" link to open it directly.
